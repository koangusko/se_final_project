# 教室 3D 拍攝流程（iPhone）

教室頁支援兩種 3D，兩種都可以上傳，同一間都有時可以切換：

|            | 3D 格局（主要）                   | 3D 實景（次要）         |
| ---------- | --------------------------------- | ----------------------- |
| 需要       | iPhone Pro（有 LiDAR）            | 任何 iPhone             |
| App 模式   | Scaniverse 或 Polycam 的 **Mesh** | Scaniverse 的 **Splat** |
| 匯出格式   | **GLB**                           | PLY，再轉成 **SPZ**     |
| 管理頁欄位 | 3D 格局                           | 3D 實景（高斯噴濺）     |

每間教室拍 3D 格局；演講廳、未來教室另外拍 3D 實景。

## 拍攝前

- 教室狀態：開燈；窗簾拉到一半；桌椅排整齊；拍攝時房間裡不要有人走動。
- 手機電量 50% 以上；一間教室約 3–5 分鐘。

## 3D 格局（LiDAR Mesh，GLB）

1. Scaniverse 選 **Mesh** 模式，範圍選最大的（Area / 大範圍）。
2. 進門後先**往下慢慢掃一遍地板**。
3. 沿著牆走一整圈，鏡頭對著牆，每一面都要掃到，牆角多停一下。手機離牆或桌面 1–3 公尺。
4. 桌椅區從兩個方向各掃一次；天花板不用掃。
5. 看螢幕上的覆蓋顏色，還沒覆蓋到的地方補掃。大教室（例如管268）分區慢慢掃，不要快速一路掃過。
6. 處理時有品質選項就選細節最高的。
7. 匯出選 **GLB**，AirDrop 到電腦，到管理頁「教室管理 → 該教室 → 3D 格局」上傳。
8. 在預覽裡轉到想要的角度，按「把目前視角存成預設」；講台方向不對就調「水平轉向」。

## 3D 實景（高斯噴濺，SPZ）

1. App 用 **Scaniverse Classic**，模式選 **Splat**。
2. 從門口開始，鏡頭朝房間內，沿著牆**慢慢**繞一圈（眼睛高度），再在腰的高度繞一圈。
3. 走到**房間中央**原地慢慢轉一圈。
4. 黑板、白板、投影幕、窗戶多停留、換角度拍。
5. 匯出 **PLY**，在 https://superspl.at/editor 清掉窗外雜點、把地板轉正。
6. 轉成 SPZ 並壓到 15–25 MB：
   ```bash
   npx @playcanvas/splat-transform clean.ply room.spz
   npx @playcanvas/splat-transform -H 1 clean.ply room.spz   # 太大時降低球諧階數
   ```
7. 清掉過大的雜點：
   ```bash
   node scripts/clean-spz.ts room.spz room-clean.spz                    # 預設移除尺寸大於 0.2 的點
   node scripts/clean-spz.ts room.spz room-clean.spz --max-scale 0.5    # 清太多時放寬
   ```
8. 管理頁「3D 實景」上傳，在預覽裡調整旋轉（Scaniverse 通常要把 X 設 180）與視角後儲存。
9. 在 3D 裡走到房間中央，按「從這個位置產生全景」，就會多一張 360 全景。

## 360 全景

- 有 360 相機（例如 Insta360）：在教室中央拍一張，匯出等距長方投影（2:1）JPEG 上傳。
- 沒有 360 相機：用上面 3D 實景的第 9 步，從高斯噴濺產生。

## 常見問題

| 狀況                      | 處理                                 |
| ------------------------- | ------------------------------------ |
| 3D 格局沒有地板、缺牆     | 補掃地板與每一面牆                   |
| 3D 實景上下顛倒           | 管理頁把旋轉 X 設 180                |
| 3D 實景被大片模糊色塊蓋住 | 用 `scripts/clean-spz.ts` 清掉再上傳 |
| 3D 實景白牆一片霧         | 改拍 3D 格局                         |
| 窗戶一團亂                | 拍攝時拉上窗簾                       |
| 手機載入很慢              | 3D 實景用 `-H 1` 再壓小              |
| 全景圖有拉扯              | 補拍房間中央原地轉一圈那段           |
